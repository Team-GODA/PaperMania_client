# PaperMania_client
*페이퍼마니아 클라이언트 레포지토리입니다.*

## 정보
- 버전 : Unity 6000.0.50f1

## 파일 관리법
- 개발에 필요한 파일 or 리소스는 적절한 폴더를 만들어 넣어준다.
- 만일 폴더가 없을 시, 새로 생성한 후 개발자들에게 폴더명을 남겨준다.

***예시***
```
Assets/
│
├── Scripts/
│   ├── Interface/       ← 인터페이스 관련
│   ├── SO/              ← SO 관련
│   ├── Player/          ← 플레이어 관련
│   ├── Enemy/           ← 적 관련
│   └── UI/              ← UI 관련
├── Animations/
│   ├── Player/          ← 플레이어 애니메이션
│   ├── Enemy/           ← 적 애니메이션
│   └── UI/              ← UI 애니메이션
```
